# Focus House — структура сайта

Презентация структуры сайта, пользовательских сценариев и CJM. Редакция от 25 ноября 2026 синхронизирована с каталогом семейств и вариантов, пояснениями допуслуг и подготовкой карты объектов. Рабочие подключения отделены от демонстрационных сценариев.

Содержимое: HTML, CSS, JavaScript и локальный шрифт Onest с лицензией OFL.

Размещение: GitHub Pages, ветка `main`, папка `/ (root)`.

После завершения согласования: отключить Pages, сохранить передаваемые файлы и удалить этот репозиторий в настройках GitHub. Скачанные другими людьми копии удаление репозитория не отзывает.
